build(blue-guardian): growth profile + payout-quality tile + learning fixes

This rolls up the conversation-era feature work onto blue-guardian: the
new full-14-symbol growth profile, per-symbol BE/trail tightening, the
payout-quality dashboard tile, the CLI overrides layer x key grid,
archive-restore for trade_log position_mgmt stamps, per-tick MAE/MFE
tracking, the payoff-paradox meter + tuner, calibrated DEAL_REASON-based
exit_reason mapping, the dashed Session Reset / Memory wipe controls,
plus 20+ new utilities/scripts and 16 new tests.

  * profiles/growth.yaml: new full-14-symbol growth campaign
    (Kelly 0.25, pyramiding on, 20% daily target, 0.7 RR floor,
    loop_interval_seconds=15, fast_mode eligible on gold/oil/SPX)

    SL/TP widening for XAUUSDm/USOILm/SPX500m, fast_mode symbol set
